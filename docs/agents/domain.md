# Domain documentation

This repository contains one repository context plus independent plugin
contexts.

- Read root `CONTEXT.md` for catalog and tooling changes.
- Read `<plugin>/CONTEXT.md` before changing that plugin's behavior.
- Read relevant decisions under `docs/adr/` or `<plugin>/docs/adr/` when those
  directories exist.
- Surface conflicts with an existing ADR instead of silently overriding it.
